# Confluence Information Architecture

## Space Structure
- `Executive Dashboard Home`
  - `Daily Briefing`
  - `KPI Definitions`
  - `Performance Narratives`
  - `Risk Register`
  - `Change Log`

## Templates
- Daily Brief template (auto date + metric deltas)
- Weekly Executive Narrative template
- KPI Deep Dive template

## Automation
