# VP-Level Executive Dashboard Theme

## Visual Direction
- Theme name: **Midnight Executive**
- Style: minimalist, high-contrast, decision-first
- Mood: confident, premium, calm under pressure

## Color Tokens
- `--bg`: #0B1220
- `--panel`: #111A2E
- `--text`: #E6EDF8
- `--muted`: #96A4C2
- `--positive`: #22C55E
- `--warning`: #F59E0B
- `--negative`: #EF4444
- `--accent`: #3B82F6

## Typography
- Primary: Segoe UI / Inter
- KPI numeric: semi-bold, tabular numbers
- Hierarchy: 32px headline, 18px section title, 14px detail

## Layout Principles
- One-screen executive story (no scrolling preference)
- 5 KPI cards at top, trends center, risks/actions right rail
- Red/amber/green statuses with explicit label and icon

## Interaction Design
- Hover details for context
- Click-through to underlying operational page
- Always-visible last refresh timestamp
